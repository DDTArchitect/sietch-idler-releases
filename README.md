# Sietch Idler

A Dune-themed idle game for Windows: gather, craft, fight, run dungeons, and build a Dune Harvester to farm spice.

## Install

1. Download **Sietch-Idler-Setup-x.y.z.exe** from the [latest release](https://github.com/DDTArchitect/sietch-idler-releases/releases/latest).
2. Run it. Windows may say **"Windows protected your PC"** because the game is not signed by a publisher. Click **More info**, then **Run anyway**.
3. The game installs and opens. A desktop shortcut is added.

## Updates

You only install once. The game checks for a new version when it starts (and every few hours while it runs), downloads it in the background, and asks you to restart. If you choose Later, it updates the next time you close the game.

## Your saves

Saves live in `%APPDATA%\Sietch Idler\saves` and are never touched by updates or uninstalling.
